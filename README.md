## Deskripsi
Praktikum ini membahas dasar-dasar JavaScript serta penggunaannya untuk memanipulasi elemen HTML. Praktikum dilakukan dengan menggunakan HTML sebagai struktur halaman web dan JavaScript untuk membuat halaman menjadi interaktif.

## Tujuan Praktikum
1. Memahami penggunaan JavaScript pada halaman web.
2. Menggunakan variabel, fungsi, dan operator.
3. Memahami percabangan `if-else` dan `switch`.
4. Mengambil serta mengubah elemen HTML menggunakan JavaScript.
5. Membuat halaman web interaktif melalui event dan manipulasi DOM.

## Daftar Latihan

### Latihan 1 — Menampilkan Pesan
Menampilkan teks Hello World pada halaman web dan menggunakan console untuk melihat output JavaScript.

### Latihan 2 — Alert dan Prompt
Menggunakan `alert()` untuk menampilkan pesan dan `prompt()` untuk menerima input dari pengguna.

### Latihan 3 — Fungsi Operasi Dasar
Membuat fungsi untuk melakukan operasi aritmetika, seperti penjumlahan, pengurangan, perkalian, dan pembagian.

### Latihan 4 — Percabangan If-Else
Memeriksa nilai yang dimasukkan pengguna untuk menentukan status lulus atau belum lulus serta memvalidasi input.

### Latihan 5 — Percabangan Switch
Menggunakan `switch` untuk menampilkan pesan berdasarkan pilihan angka yang dimasukkan pengguna.

### Latihan 6 — Cek Bilangan Genap atau Ganjil
Menerima input bilangan dari pengguna dan menentukan apakah bilangan tersebut genap atau ganjil.

### Latihan 7 — Mengubah Warna Latar Halaman
Menggunakan fungsi JavaScript untuk mengubah warna latar halaman menjadi hijau muda, putih, atau kuning muda melalui tombol.

### Latihan 8 — Daftar Menu Makanan
Menggunakan checkbox dan JavaScript untuk menghitung total harga makanan berdasarkan menu yang dipilih.
